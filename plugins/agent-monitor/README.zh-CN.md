# agent-monitor

看清 Claude Code 子代理在做什么：运行时在输入框上方显示实时条带，`/sub` 面板里有本项目的子代理历史、告警、每个代理的详情页和花费估算。

[English](README.md)

> 需要 Claude Code ≥ 2.1.287。

## 功能

- **实时条带**：每个运行中的子代理一行，显示在输入框上方：类型、模型与档位、任务、当前动作，然后是 `ctx% · 令牌 · $ · m:ss`，有告警时行末一个红色 `!`。
- **`/sub` 历史**：本项目所有子代理，含以前的会话：数据读自 Claude Code 存在 `~/.claude/projects/` 下的会话记录，所以 `/clear` 和新会话后仍在（新的在前）。运行中的代理排在前面，每个三行：带档位前缀的描述（`op.med · 任务`）；`类型 · 模型 · 档位`，档位不符时加 `≠ 要求 <档位>`，后面是当前动作（截断，不滚动）；上下文填充条和 `ctx% · 令牌 · $ · m:ss`。已结束的代理进密集对齐表 `# desc type tier cost time`：`#` 是状态符号，cost 写作 `ctx% · 令牌 · $`（`41% · 86.2k · $0.42`）。用 ↑/↓ 选行。
- **PR 模式与 Agent 模式**：`/sub` 默认进入 PR 模式：`Title` 列下一个 PR 一组，显示子代理数、令牌、花费、时长（墙钟时间）和 PR 状态（Open / Merged），当前分支的 PR 置顶并展开（还没有子代理时也显示）；在分组行按 Enter 展开或收起。不属于任何 PR 的子代理进灰色的「其他」组。归属先看子代理描述里的第一个 `#N`（`op.med · #42 …`）：编号为 N 的 PR，或正文写了 `Closes #N` 的 PR。描述里没有时看它启动时所在的分支（会话记录第一行）：票分支 `<前缀>/<N>-<slug>` 同样处理，PR 自己的 head 分支（如 `spec/` 集成分支）归到该 PR；`dev`、`main` 等其余分支进「其他」。从 `dev` 或 `main` 发出的发版 PR 从不认领子代理。PR 列表来自 `gh pr list`（近期 open 与 merged，每 5 分钟刷新，拉取失败保留上一份），所以 PR 模式需要已登录的 GitHub CLI。面板头部 `[PR] [Agent]` 或按 `p` / `a` 切换；Agent 模式是不分组的列表。两种模式下每个代理都按上面的行版式显示。
- **按 PR 公开的合计**：每个有子代理的 PR，公开其子代理的令牌、估算花费、时长（同时在跑的子代理只算一次）和 hook 拦截次数（被 hook 拒绝的工具调用；命令执行失败不算）；主会话从不计入。[pr-hint](../pr-hint) 把它们显示在 PR 卡片上。agent-monitor 不读取任何其他 mod 的值，没有它们也照常工作。
- **详情页**：在行上按 Enter 打开，按时间线排列：指令；步骤（状态、起止时间，然后是最近的动作）；改过的文件（含 `+/−` 行数）；该代理的告警及其时间和原因。之后是令牌（缓存命中 / 未命中 / 输出）与**估算花费**、工具次数、技能和结果。没有告警的代理不显示告警段。按 `b` 返回。
- **告警**：有任一告警的代理行末一个红色 `!`。表格上方是告警时间线（按时间从早到晚，显示最新四条），每条写明时间、符号和真实原因：
  - `!` **文件冲突**：两个代理（或代理与主会话）在同时运行期间改了同一个文件；写明双方和路径。
  - `~` **卡住**：运行中的代理在阈值时长内没有任何步骤或工具调用（到阈值为黄色，两倍为红色）；写明未返回的工具。每个代理只弹一次提示。
  - `≠` **档位不符**：代理实际运行的模型或档位与描述前缀不一致（见下）；写明要求的档位和实际档位。
  - `×N` **拦截**：工具调用被 hook 拒绝或报错：每种原因一行，写明原文和 `×N`。
- **位置**：`/sub` 打开面板；`/sub top` 固定在输入框上方，`/sub right` 停靠在右侧面板（跨会话记住）；`/sub set` 打开面板内的设置页。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/sub` | 显示面板（再次输入则关闭） |
| `/sub top` · `/sub right` | 把面板放在输入框上方 / 右侧面板 |
| `/sub set` | 打开设置页（切换列、开关、位置、卡住阈值；`w` 保存） |

宿主若拒绝 `/sub`，mod 改注册 `/subs`。

## 档位前缀（可选）

**Tier** 列根据代理实际运行的模型显示 `model.effort`（如 `sonnet.med`）。如果派发子代理时把描述写成 `<model>.<effort> · 任务` 的形式——模型取 `so`、`op`、`ha`、`fa`，档位取 `low`、`med`、`high`，例如 `so.med · 修登录表单`——mod 会把这个前缀当作你**要求**的档位，在代理实际跑了别的模型或档位时报 `≠` 告警。**没有前缀就不做比较，档位告警永远不会触发。**

## 设置

在 **/config** 里选 agent-monitor，面板选项也可以用 `/sub set`。

| 设置 | 默认 | 含义 |
| --- | --- | --- |
| Language | `auto` | `auto` 先看 Claude Code 的语言设置，再看系统语言；`en` 或 `zh` 强制指定。默认英文。 |
| Scope | 空 | 只在该目录（绝对路径，如 `/home/me/work`）及其子目录里运行；留空 = 所有目录。 |
| 卡住阈值 | 3 分钟 | 运行中的代理空闲多久后标记。 |
| 输入框上方实时行 | 开 | 每个运行中的子代理一行。 |
| 告警区 / 弹出提示 | 开 | 表格上方的告警整句；首次发现冲突或卡住时弹一次提示。 |
| `/sub` 默认位置 | `last` | `last`、`right` 或 `top`。 |
| 列 | 全开 | 已结束表的 Tier、Cost、Time 列；告警标记（红色 `!`）。 |
| 模型价格 | API 标价 | 紧凑 JSON，美元 / 每百万令牌：`{"sonnet":[输入,缓存写入5m,缓存读取,输出],...}`。没写的系列用默认值，JSON 无效则全部回退默认。 |

花费只是按令牌数和标价算出的**估算**（不含批处理、快速模式、区域加价）；没有价格的模型显示破折号。

## 安装

在 Claude Code（2.1.287 或更高）里：

```
/plugin marketplace add nokiy/claude-code-mods
/plugin install agent-monitor@nokiy-mods
```

第一条把本仓库添加为插件市场（只需一次），第二条从中安装这个 mod。之后开一个新会话即可。
