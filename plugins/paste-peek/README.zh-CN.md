# paste-peek

往 Claude Code 输入框里粘贴图片，**发送前**就在输入框上方看到清晰原图。

[English](README.md)

```
 ┌────────────┐  ┌────────────┐
 │    图片    │  │    图片    │      ← 粘进这个输入框的每张图
 └────────────┘  └────────────┘
 [Image #1] 1304×400 · 76 KB   [Image #2] 926×864 · 113 KB   ← 选中的那张高亮
 ⌥↑ 居中放大   ⌥↓ 右侧放大   ⌥← ⌥→ 换图
 > 这两张截图哪里有问题？[Image #1] [Image #2]
```

## 功能

- **粘贴图片**（ctrl+v）后 1 秒内，只在**这个会话**的输入框上方出现缩略图；只复制不粘贴不会显示，其他会话也不会弹出。
- **多张图**并排显示，选中的那张说明文字高亮。
- **居中放大**选中的图，或在**右侧面板**里放大（占满屏幕高度，全屏布局下停靠在右边）。
- **发送**后预览自动清空。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| **⌥←  ⌥→** | 上一张 / 下一张（两张及以上） |
| **⌥↑** | 居中放大选中的图，再按收起 |
| **⌥↓** | 右侧面板放大，再按收起 |
| ⌥→（只有一张图） | 同 ⌥↓ |

放大状态下 ⌥← ⌥→ 会直接换放大的图。输入框里没有图时，所有按键保持原样（⌥← ⌥→ 按词移动光标）。

## 使用条件

- **Claude Code 2.1.287 及以上**（mod 功能）。
- **macOS**：通过 `osascript` 读剪贴板。
- **前台会话里的 Ghostty 或 kitty**：图片走 kitty 图形协议。其他终端、后台会话（`claude --bg`）画不出图，mod 每个会话检测一次，画不了就什么都不显示。
- `python3`（可选）：测量终端字符格的真实宽高，比例更准；没有就按高是宽的 2 倍估算。

## 已知限制

- 居中放大的大小受输入框上方区域限制，全屏布局下约半个屏幕；要更大请用右侧面板（⌥↓）。
- ⌥↑ / ⌥↓ 借用了 diff 面板「上一个 / 下一个文件」的快捷键，diff 面板打开时归它用。
- 刚粘贴完，光标在输入框最末尾，此时 ⌥→ 不会通知 mod；先按一次 ⌥←，之后左右都能用。
- 图片是在 `[Image #N]` 出现时从剪贴板读取并对应的，所以要用剪贴板粘贴，拖入文件对应不上。

## 设置（`/config`）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| Language | `auto` | `auto` 跟随 Claude Code 的 `language` 设置，其次看系统语言；可选 `en`、`zh` |
| Debug log | 关 | 把粘贴、画图检测、尺寸等写到 `/tmp/paste-peek/debug.log` |

命令：`/peek` 打开面板 · `/peek why` 查看能否画图 · `/peek log`（需开调试日志）· `/peek clear`。

## 隐私

数据不离开你的 Mac：不联网，不消耗模型 token。

| 程序 | 何时 | 用途 |
| --- | --- | --- |
| `osascript`（JavaScript） | 输入框出现新的 `[Image #N]` 时 | 读剪贴板里的图片，存成 PNG 到本会话的临时目录；从不读剪贴板文字 |
| `sips` | 仅当终端读不了文件时 | 缩小 PNG 以字节方式发送 |
| `python3` | 终端宽度变化时 | 读终端像素尺寸（字符格比例） |
| `sh` / `mkdir` / `base64` | 会话开始时 | 写一个 1×1 PNG，用来检测能否画图 |
| `rm` | 会话结束时 | 删除本会话临时目录 `/tmp/paste-peek/<会话 ID>/` |
| `tail` / `sh` | 仅开启调试日志时 | 读写 `/tmp/paste-peek/debug.log` |

输入框内容只用于查找 `[Image #N]`，不保存。
